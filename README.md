# 🌱 EcoNova: Smart City Waste Segregation & Carbon Accounting

EcoNova is an intelligent civic waste management ecosystem designed to automate household waste segregation, calculate live carbon offsets, and dynamically coordinate municipal collection routes.

---

## 🚀 Key Features

* **📸 Intelligent Waste Scanner**: Heuristic visual classification across 8 municipal waste streams (Metal, E-Waste, Plastic, Paper, Organic, Glass, Textiles, Hazardous) with auto-estimated unit weights.
* **🗑️ Municipal Bin Color Guidance**: Instant color-coded bin routing (Green, Blue, Black, Red) ensuring proper residential sorting at source.
* **🌍 Live Carbon Offset Math**: Real-time conversion of diverted waste into avoided $CO_2e$, equivalent driving kilometers offset, and urban tree absorption days.
* **🎬 EcoShorts Micro-Learning**: Civic awareness feed delivering practical DIY upcycling tutorials and recycling guidelines.
* **📍 GIS Hotspot Navigator & Driver Queue**: Interactive dark-matter map for citizens to geotag illegal dumps and municipal collection crews to clear tasks in real time.

---

## 🛠️ Tech Stack

* **Framework**: Streamlit
* **Computer Vision**: PIL (Pillow) multi-spectrum chromatic and luminance heuristics
* **Geospatial Mapping**: Folium & Streamlit-Folium
* **Data Processing**: Pandas & NumPy
* **Design**: Modern Glassmorphism & Cyber-Eco Dark Theme
